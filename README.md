# Codex Custom Pets

Animated ChatGPT Work pet source assets, final sprite sheets, previews, and validation reports.

## Pets

| Pet | Description | Stable pet ID |
| --- | --- | --- |
| Grievous Mask | Bone-white, horned cyborg mask with watchful red eyes | `pet_6abe49473a888191a4b73eb53bbcdd27` |
| Sauron | Dark-iron spiked helm with an ember-red visor | `pet_6abe517a2fe08191b006b1e2134f59e3` |

Each pet folder contains its final v2 sprite sheet, source images/strips, contact sheet, motion previews, and QA reports. The v2 sheets use an 8-column by 11-row layout at 1536x2288 pixels.

## Contents

- `pets/<pet>/spritesheet-extended.png` — final validated sprite sheet
- `pets/<pet>/source/` — canonical base and generated source strips
- `pets/<pet>/previews/` — per-state GIFs, full motion previews, and contact sheets
- `pets/<pet>/qa/` — validation, motion, direction, and continuity reports

This repository is intended to be private because the pets are character-inspired artwork.
