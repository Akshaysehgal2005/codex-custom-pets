# Source notes — Henry

Character: Henry, from Little Fighter 2. The nine standard animation rows use frames directly extracted from the original indexed sprite sheets and scaled with nearest-neighbor interpolation. Sixteen look directions are supplemental pixel-art interpretations generated for the ChatGPT Pets v2 layout.

Original game sprite archive: [Project F / LF2_19](https://github.com/Project-F/LF2_19). The upstream sprite archive says these sprites originate in Little Fighter 2 and are © Marti Wong and Starsky Wong.
